# Infernum Bestiary

A fan-made, multi-page reference site for the Calamity Infernum mod for Terraria.

- A hub page with bosses grouped by game stage, with image previews on hover
- Around 50 separate boss pages
- Plain HTML and CSS, no build step and no frameworks

## Run locally

Download the repository and open `index.html` in a browser.

## Structure

- `index.html` is the landing page
- `bestiary/` is the hub page
- `bosses/` has one page per boss
- `css/` has the shared stylesheet
- `images/` has the boss images
